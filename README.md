
# Find Your Perfect Board Game

## The problem

A person planning a game night for up to six players needs a board game that accommodates their entire group because not every game supports the same number of players. My page will let them select their group size and display board games that everyone can play.

### Sections

- Page heading and problem sentence
- Dropdown to select 1–6 players
- Cards displaying matching board games
- Message when no games match

### User action

- A visitor selects the number of players from a dropdown, and the page displays games that support that group size.
